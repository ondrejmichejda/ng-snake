# ng-snake

Angular app scaffold for the snake game.

## Commands

- `npm run start`: run the dev server at `http://localhost:4200/`
- `npm run build`: build to `dist/`
- `npm run test`: run unit tests with Karma
- `npm run format`: check formatting with Prettier
- `npm run format:write`: format files with Prettier

## Project structure

- `src/`: application source code
- `public/`: static assets

## Formatting

Prettier is configured via `.prettierrc`.

## Testing

Unit tests live next to source files as `*.spec.ts` and run with Karma.
